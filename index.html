How to Run Automation on MyClassboard (Zero Setup)

1

Save the Bookmarklet

Drag the blue "🚀 MCB Auto Asset" button above into your browser's Bookmarks bar. (If bookmarks bar is hidden, press Ctrl + Shift + B in Chrome/Edge).

2

Navigate to MyClassboard

Log in to meridian.myclassboard.com and open:
Inventory → Asset Management → Fixed Assets Management

3

Click the Bookmarklet

Click MCB Auto Asset in your bookmarks bar. A floating assistant window will appear directly on top of the MyClassboard page!

4

Click "Detect Last Number" & Start

The assistant will automatically scan the visible table for the previous asset, pre-fill the next numbers, and when you click Start Automation, it enters each item and saves sequentially!

Alternative: Run via Browser Console (F12)

On MyClassboard page, press F12 (or right-click → Inspect), open the Console tab, paste the script, and press Enter.

🌐 Hosting this Web App on GitHub Pages (Free & Public)

  1. Push this project directory to a new GitHub repository (e.g. meridian-asset-assistant).
  2. In your repository, go to Settings → Pages.
  3. Under Branch, select main (or master) and folder / (root), then click Save.
  4. In ~60 seconds, your site will be live at: https://<your-username>.github.io/<repo-name>/! Anyone on the team can use it immediately without installing anything.
